# BAHATI Arsene Portfolio

A dark, yellow-accented personal portfolio inspired by the reference design.

## Before publishing
1. Replace the portrait placeholder in `index.html` with your own photo.
2. Replace `your-email@example.com` with your real email.
3. Replace the GitHub profile link with your actual GitHub URL.
4. Check the project links and descriptions.
5. Open `index.html` in a browser to preview.

## Publish with Vercel
1. Create/sign in to GitHub.
2. Create a new repository, for example `bahati-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Go to Vercel and import the GitHub repository.
5. Deploy. Vercel will give you a public URL you can submit to your lecturer.

## Photo
For best results, use a clear professional headshot with a simple background.
